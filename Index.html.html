1. Performance & Speed Optimization

• ប្រើប្រាស់ **Redis Caching** សម្រាប់បកប្រែ Query ញឹកញាប់
• បំលែងរូបភាពជា **WebP/AVIF** format រួមជាមួយ Lazy Loading

• Hash Password ដោយ **Argon2id** ឬ **bcrypt**

• រចនាឡើងផ្តោតលើទូរស័ព្ទដៃជាចម្បង (Mobile-First Layout)
